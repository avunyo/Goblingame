# Новые противники

Созданы четыре low-poly интерпретации предоставленного референса. Модели гоблина и его анимации сохранены.

| Персонаж | Файл Blender | Здоровье | Роль |
| --- | --- | --- | --- |
| Крысолов | RatRogue.blend | 120 | Быстрый ловкач с кинжалом и хвостом |
| Грибоед | MossGourmand.blend | 320 | Медленный тяжёлый гриб с мхом |
| Костяной страж | BoneSentinel.blend | 240 | Скелет в шлеме со щитом и мечом |
| Железный клык | IronTusk.blend | 600 | Клыкастый мини-босс с молотом |

В каждом .blend есть отдельный Armature, привязанная к костям сетка, материалы и действия Idle / Walk. У крысолова 22 кости, у остальных по 16. Модель можно открыть двойным щелчком, выделить Armature и выбрать нужное действие в Dope Sheet → Action Editor. Ходьба зациклена на месте; позицию в игре меняет контроллер.

В Unity открывай Assets/Scenes/GoblinPlayable.unity. Четыре врага находятся в объекте Enemy Cast. Их FBX, портреты и карточки лежат в Assets/EnemyCast, префабы и Animator Controllers — в подпапке Generated с номером, созданной при успешной настройке.

Play: WASD — ходьба; Shift — бег; C — боевой режим; ЛКМ — удар; Q — головой; ПКМ — блок. Подойди к врагу в боевом режиме для боя. Враги патрулируют рядом с начальной позицией и вступают в бой вблизи. Победа даёт опыт. Для повторного теста враг восстанавливается через 12 секунд. Это простое тестовое поведение без поиска пути по сложным препятствиям; атака пока показана наклоном корпуса, отдельные боевые клипы для новых врагов не создавались.

Интерфейс: металлические рамки, портреты, зелёное здоровье гоблина (200), красное здоровье ближайшей цели, фиолетовый опыт и уровень. Tab открывает/закрывает карточки противников по мотивам референса. Числа отображают реальные игровые значения, а не статичную картинку.

Исходная сцена сохранена в резервной GoblinBeforeEnemyCast. Скрипты создания моделей: ArtSource/create_enemy_cast.py и finish_enemy_cast.py. Генератор отказывается перезаписывать уже существующие .blend. validation.json содержит проверку движения костей и совпадения крайних кадров ходьбы.
